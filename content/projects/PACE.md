## Background

Nonprofit organizations often collect valuable operational and program data but face challenges in transforming that information into accessible insights that demonstrate impact. PACE maintains extensive data on its partner organizations and capacity-building programs, yet the organization sought improved tools to visualize program outcomes and track organizational growth over time.

This project aimed to help PACE convert existing program data into a structured dashboard that clearly communicates the organization’s impact. In addition to visualizing program metrics, the project focused on identifying meaningful indicators that demonstrate how PACE’s intensive services contribute to strengthening the capacity of participating organizations.

## Project Details

Our team collaborated with PACE to analyze program data and develop tools that improve both impact reporting and program evaluation.

**Workstream 1: Program Impact Dashboard Development**

- Conducted exploratory data analysis (EDA) on existing program datasets to understand available variables and data structure.
- Cleaned and prepared datasets to ensure consistency and usability for analysis and visualization.
- Developed visualizations highlighting program reach, organization participation, and program outcomes.
- Designed an interactive dashboard that communicates PACE’s impact and program performance in a clear and accessible format.

**Workstream 2: Capacity Growth Metric Identification**

- Analyzed data related to organizations participating in PACE’s Intensive Services (IS) program.
- Identified measurable indicators of organizational growth, such as budget expansion, staffing levels, and operational capacity.
- Conducted data mining to evaluate trends in these indicators over time.
- Developed a framework for assessing whether participation in PACE programs contributes to improved organizational capacity.

## Deliverables

- **Program Impact Dashboard**  
  A structured dashboard enabling PACE staff to easily access participant-level and program-level data while visualizing the organization’s impact.

- **Data Preparation & Visualization Framework**  
  Cleaned datasets and visualization structures designed to support ongoing dashboard updates and program monitoring.

- **Capacity Growth Analysis Report**  
  A report identifying key indicators of organizational improvement and evaluating the effectiveness of PACE’s Intensive Services program.

- **Strategic Recommendations**  
  A set of actionable insights and recommendations to help PACE better track program outcomes and communicate organizational impact.

- **Final Presentation**  
  An executive presentation summarizing findings and recommendations delivered to the PACE team.

## Outcomes

This project enhanced PACE’s ability to communicate its impact through data-driven storytelling and interactive visualization tools. By transforming existing program data into an accessible dashboard and identifying key metrics for measuring organizational growth, the project provides PACE with a framework for evaluating program effectiveness and demonstrating the value of its capacity-building initiatives.
